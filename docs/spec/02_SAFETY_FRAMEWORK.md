# Safety Framework

**Drone Surveying in Mining — Interactive Training Simulator**  
Created / initiated by **MD Salim Ansari**

This project contains educational safety simulations and generic SOP templates.
They are not a substitute for applicable law, mine/site SOPs, manufacturer
instructions, aircraft qualification, competent supervision, or current
regulatory requirements.

## Safety priorities

1. Protect people.
2. Stop or redesign unsafe work.
3. Follow applicable site controls and authorization.
4. Protect the aircraft and equipment.
5. Protect the integrity of survey data.
6. Report incidents and near misses.
7. Learn and improve the procedure.

## Important

Exact operating limits, emergency actions, battery handling, RTH behavior,
flight permissions, airspace rules, PPE, blast controls and separation
requirements must be taken from the current applicable sources.

## Public repository rule

Do not commit real mine coordinates, operational flight logs, private imagery,
credentials, API keys, security layouts, confidential documents or restricted
datasets.
