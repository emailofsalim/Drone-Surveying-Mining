Do not treat older drafts, PPT instructions, or unrelated mine-survey presentation files as required source material. This pack intentionally contains only the current Drone Surveying in Mining web-app source/instruction files.

Build incrementally by phase. Do not implement the entire application in one pass. Preserve technical assumptions, safety caveats, simulated-data labels, CRS/height-reference metadata, raw-data provenance, and the distinction between educational simulation and real aircraft/regulatory operation.
