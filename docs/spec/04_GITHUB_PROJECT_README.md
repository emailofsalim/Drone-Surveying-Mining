# Drone Surveying in Mining — Interactive Training Simulator

**Created / initiated by MD Salim Ansari**

An open-source, browser-based educational platform for learning Drone/UAV
Surveying in Mining from first principles through final engineering outputs.

## Vision

The platform teaches the complete chain:

`Drone → Flight → GNSS/IMU/Compass → Mission → Data → Photogrammetry/LiDAR → Point Cloud → DSM/DTM → Orthomosaic → Volume → QA/QC → Engineering Decision`

## Repository goals

- 3D drone anatomy and flight simulation
- Aerodynamics and flight-control laboratories
- IMU, compass and magnetic-error training
- True / magnetic / grid north
- CRS, datum, UTM, geoid and height/RL laboratories
- GNSS / RTK / PPK / CORS / NTRIP concepts
- GSD and image-overlap calculators
- Mission-planning and pre-flight simulation
- RGB, LiDAR, thermal and multispectral modules
- Keypoint / tie-point / triangulation / bundle-adjustment visualization
- Point cloud, DSM, DTM, TIN, orthomosaic, contours and volume workflows
- GIS/CAD/mine-planning workflow
- QA/QC and failure-diagnosis laboratories
- Complete open-pit mining case studies

## Important

This is an educational simulator. It is not an aircraft certification system,
legal compliance guarantee, manufacturer-certified simulator, or substitute
for applicable laws, manufacturer instructions, mine SOPs or competent
professional supervision.
